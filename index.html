AIHelper Support · Privacy Policy

Your Mac workspace, on iPhone.

AIHelper is a free iPhone client for a compatible AIHelper Mac Bridge. It lets you browse projects and conversations, send messages to your own Mac agent, and read replies and execution events. It is not a hosted AI service and is not affiliated with OpenAI.

Try it without a Mac

Choose 离线演示 / Offline demo on the connection screen. Open a sample conversation to explore Markdown, code blocks, copying, and typing. Sample replies are bundled text, not model-generated answers. Demo input stays in memory and is discarded when the demo closes.

Live workspace requirements

You need a Mac running a compatible AIHelper Bridge and an execution owner such as a configured Codex agent. The Mac agent supplies its own model access, credentials and permissions. AIHelper does not sell or include model access. The live interface currently uses Simplified Chinese; setup guidance and offline samples include English.

  1. Start your existing compatible Bridge on the Mac. The Bridge displays its address and pairing information.
  2. Connect the iPhone and Mac to a reachable network, usually the same trusted Wi-Fi network.
  3. In AIHelper, use 扫描局域网 Bridge (Scan) or paste the Bridge pairing string into 手动粘贴配对串. A pairing string has the form ws://host:port|token.
  4. Allow local-network access if iOS requests it. Open a project or create a conversation and select an available Mac agent.

The companion Bridge is not included in the iPhone download. If you do not already have a compatible installation, contact support for setup assistance before relying on live functionality. Do not publish private source code or credentials in a support request.

Connection troubleshooting

  • Keep the Mac awake and the Bridge running. Confirm the address and port in the Mac Bridge output.
  • If discovery finds nothing, use manual pairing with the actual Mac address. Guest Wi-Fi, firewalls and VPN routes may prevent device-to-device traffic.
  • Check iOS Settings → Privacy & Security → Local Network → AIHelper. Allow only the permissions needed for your use.
  • If an agent is unavailable, verify its setup on the Mac. AIHelper cannot grant permissions or start another execution owner to bypass it.

Security and photos

Use a trusted network. Keep pairing tokens private and do not expose your personal Bridge on the public internet. Photo access is optional; only attachments you select are sent to your paired Mac. The Mac agent and model provider may process submitted content under their own policies.

Contact support

Open a support request. Include your iOS version, AIHelper version and the error text. Remove pairing tokens, screenshots of private conversations and other sensitive information. GitHub requests are public; GitHub applies its own privacy policy.
